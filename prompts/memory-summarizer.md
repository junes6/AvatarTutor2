# 세션 요약 → 장기기억

방금 끝난 대화에서, 튜터 {{name}}가 다음 대화에서 기억하고 이어가면 좋은 정보를 추출하세요.

## 추출 대상
- recent: 학습자의 근황·최근 일 (예: "지난 주말 부산 여행을 다녀옴")
- interest: 취향·관심사 (예: "매운 음식을 좋아함", "뉴진스 팬")
- promise: 학습자가 말한 계획·약속 (예: "다음 주에 운동 시작하기로 함") — 다음에 물어봐줄 것
- mistake: 자주 틀리는 영어 패턴 (예: "과거시제를 자주 놓침")
- profile: 기본 정보 (직업, 사는 곳, 가족 등)

## 규칙
- 다음 대화에서 "그거 어떻게 됐어?"라고 물어볼 가치가 있는 것만. 사소한 것은 버리세요.
- 최대 5개. 각 항목은 한국어 한 줄.
- 이미 기억에 있는 내용과 중복되면 제외하세요. 기존 기억: {{existingMemory}}

## 출력 형식 (JSON만)
{
  "facts": [
    {"text": "한 줄 요약", "kind": "recent|interest|promise|mistake|profile"}
  ]
}
