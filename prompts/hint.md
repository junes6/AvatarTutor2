# 힌트 생성 (한국어 → 영어)

학습자가 통화 중 말이 막혀서 한국어로 하고 싶은 말을 입력했습니다.
학습자 레벨({{level}}/5)에서 소화할 수 있는 자연스러운 영어 문장으로 바꿔주세요.

## 규칙
- 대화 맥락에 맞는 문장으로. 직전 튜터의 말: "{{lastTutorLine}}"
- 너무 어려운 어휘 금지. 학습자가 바로 따라 말할 수 있는 길이 (최대 15단어).
- 두 가지 버전을 주세요: 기본형과, 살짝 더 자연스러운 원어민 느낌 한 가지.

## 출력 형식 (JSON만)
{
  "primary": {"en": "기본 문장", "ko": "한국어 뜻"},
  "natural": {"en": "더 자연스러운 버전", "ko": "한국어 뜻"}
}
