# 레벨 테스트 평가

학습자가 1분간 자유 발화한 내용(STT 전사)입니다. 영어 레벨을 평가하세요.

## 레벨 기준
- 1: 단어 나열 수준, 문장 구성이 거의 안 됨
- 2: 짧은 기본 문장 가능, 오류 빈번 (CEFR A2)
- 3: 일상 주제로 대화 지속 가능, 시제·관사 오류 있음 (B1)
- 4: 유창하게 의견 표현, 가끔 어색한 표현 (B2)
- 5: 자연스러운 원어민급 표현 구사 (C1+)

## 주의
- STT 전사라서 문장부호·대문자는 평가 대상이 아닙니다.
- 발화량이 너무 적으면 (10단어 미만) 레벨 2로 두고 note에 그렇게 적으세요.

## 출력 형식 (JSON만)
{
  "level": 1~5,
  "note": "학습자에게 보여줄 한국어 한 줄 평가 (격려 톤, 강점 1개 + 성장 포인트 1개)"
}
